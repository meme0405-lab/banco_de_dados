# Banco de Dados - Pessoas Desaparecidas

Um banco de dados centralizado e acessível dedicado ao registro e busca de informações sobre pessoas desaparecidas. Este projeto visa facilitar a disseminação de informações e coordenação entre autoridades, famílias e voluntários na busca por pessoas desaparecidas.

## 📋 Objetivo

Este repositório mantém um banco de dados estruturado contendo informações sobre casos de desaparecimento de pessoas, permitindo:

- **Registro centralizado** de casos de desaparecimento
- **Busca e filtros** por diferentes critérios (nome, data, localização, características)
- **Compartilhamento de informações** com autoridades e voluntários
- **Acompanhamento de casos** e atualizações de status
- **Coordenação comunitária** na busca de pessoas desaparecidas

## 🗂️ Estrutura do Banco de Dados

O banco de dados inclui as seguintes informações principais:

### Tabelas Principais

- **Pessoas**: Dados demográficos e características físicas
- **Desaparecimentos**: Informações sobre o caso (data, local, circunstâncias)
- **Atualizações**: Histórico de mudanças e descobertas
- **Contatos**: Informações de quem reportou o caso
